import { Animate, AnimateGroup, Direction } from './AnimModule';

// single node
await Animate.popIn(node).promise;

await AnimateGroup.staggerPopIn(items, { staggerDelay: 0.06 }).promise;

await Animate.sequence([
    Animate.popIn(title),
    Animate.slideIn(panel),

Enter #

Sequencer Builder #

Build animation combos visually. seq = wait for completion, par = fire and continue to next. Собери комбо анимаций визуально. seq = ждать завершения, par = запустить и перейти к следующей. 可视化构建动画组合。seq = 等待完成，par = 触发后继续下一个。

💡 How seq / par worksКак работает seq / parseq / par 如何工作

seq(A) → par(B) → seq(C) means: run A and wait. Then start B and C together, wait only for C. B runs in the background. seq(A) → par(B) → seq(C): запускаем A, ждём. Затем B и C стартуют вместе, ждём только C. B работает фоном. seq(A) → par(B) → seq(C)：运行 A 并等待。然后同时启动 B 和 C，仅等待 C。B 在后台运行。

AnimSequencer #

Orchestrate complex animation sequences mixing sequential and parallel steps. Оркестрирует сложные последовательности анимаций, смешивая sequential и parallel шаги. 编排混合顺序和并行步骤的复杂动画序列。 

import { AnimSequencer, Animate } from './AnimModule';

await AnimSequencer.create()
    .seq(() => Animate.popIn(title))          // 1. wait
    .par(() => Animate.fadeIn(background))     // 2. fire, don't wait
    .seq(() => Animate.slideIn(panel))         // 3. starts with #2, wait
    .seq(() => Animate.pulse(cta, { loop: true }))
    .play().promise;
